# BEGame 使用教程

> 本教程介绍游戏模块、实例与状态的编写。先完成[接入配置](../docs/getting-started.md)，再阅读[架构与资源归属](../docs/architecture.md)。

## 配置 BEGame

需要在全局入口文件中配置 BEGame(只需要配置一次)

示例(仅供参考，具体配置请按类型来)

```typescript
import { logLevel } from "@begame/core/utils";
import { initBEGameServer } from "@begame/core/server";

initBEGameServer({
    logLevel: logLevel.debug, //日志级别
    debugMode: true, //debugMode开关
    onEnd: onEnd, //执行/game end后触发
    hub: Hub, //玩家执行/hub时触发
    onJoin(p) {
        //玩家进入游戏时执行(可传送到大厅等)
    },
});
```

## 如何创建游戏模块

要创建一个游戏模块，首先创建游戏 context 与 player，最后创建 module。

> 注: 以下类名仅作为示例

```ts
//context.ts
import { GameContext } from "@begame/core";
export class MyGameContext extends GameContext {}
```

```ts
//player.ts
import { GamePlayer } from "@begame/core/gamePlayer";

export class MyGamePlayer extends GamePlayer {}
```

```ts
//module.ts
import { createGameModule } from "@begame/core";
import { MyGamePlayer } from "./player";
import { MyGameContext } from "./context";
export const MyGameModule = createGameModule({
    playerClass: MyGamePlayer,
    contextClass: MyGameContext,
});
```

## 如何创建游戏类(GameEngine)

继承 module.Engine 可以创建 GameEngine 类，也即游戏类。

```ts
//game.ts
import { MyGameModule } from "./module";

export class MyGameEngine extends MyGameModule.Engine {
    protected override buildContext(config: unknown): MyGameContext {
        //在这里构建游戏context
    }

    override onStart(): void {
        //开始游戏时调用
    }

    override onStop(): void {
        //游戏结束时调用
    }
}
```

### GameEngine<P, C, O> — 常用属性与方法

> 注：以下仅列出常用成员，未注明修饰符的默认为 `public`。

#### 泛型

-   `P`: 玩家类型
-   `C`: 上下文（Context）类型
-   `O`: 上下文构建所需的配置类型

使用 `class MyGame extends GameModule.Engine<O>` 时，仅需指定 `O`（可选）。

#### 属性

-   `context: C`: 全局游戏上下文
-   `key: string`: GameEngine 在 GameManager 中的唯一 key
-   `logger: Logger`: 日志打印工具
-   `playerManager: GamePlayerManager<P>`: 玩家管理器
-   `groupBuilder: PlayerGroupBuilder<P>` _(getter)_: 玩家组构建器
-   `isActive: boolean` _(getter)_: GameEngine 是否处于激活状态
-   `isDaemon: boolean` _(getter)_: 是否为常驻游戏(大厅类，可重写)

#### 方法

-   `protected buildContext(config: O): C` _(abstract)_: 构建 context，在构造时执行，可访问 playerGroup 与 playerBuilder，其他方法不可用
-   `protected onStart(): void` _(abstract)_: 游戏开始时调用
-   `protected onStop(): void` _(abstract)_: 游戏结束前调用(清空状态与事件前)
-   `pushState(stateType, config?): GameEngine<P, C, O>`: 添加一个新的 State
-   `popState(): void`: 弹出当前 State
-   `getState<T>(stateType): T | undefined`: 获取指定 State 实例(必须已添加)
-   `deleteState(stateType): void`: 删除指定 State
-   `stats(detail?: boolean): string`: 获取游戏调试状态字符串
-   `stopGame(): void`: 停止游戏运行

### 示例

```ts
import { PlayerGroup } from "@begame/core/gamePlayer";
import { DirtShopContext } from "./context";
import { DirtShopConfig } from "./interface";
import { DirtShopMoudle } from "./module";
import { DirtShopLoadState } from "./states/loadState";
import { EntityTypeIds } from "@begame/core/utils/vanila-data";
import { GameMode, world } from "@minecraft/server";
import { Dimensions } from "@begame/core/constants";
// 常驻根 State 中组合 AutoStopComponent，见房间生命周期指南。

//配置类型O
export class DirtShopGame extends DirtShopMoudle.Engine<{
    host: PlayerGroup;
    attacker: PlayerGroup;
    config: DirtShopConfig;
}> {
    protected override buildContext(config: {
        host: PlayerGroup;
        attacker: PlayerGroup;
        config: DirtShopConfig;
    }): DirtShopContext {
        const host = this.groupBuilder.fromGroup(config.host); //构建房主队伍
        const attacker = this.groupBuilder.fromGroup(config.attacker); //构建玩家队伍
        return new DirtShopContext(host, attacker, config.config);
    }

    override onStart(): void {
        this.pushState(DirtShopLoadState); // 根 State 中配置房间回收组件
    }

    override onStop(): void {
        //执行清理
        this.killEntity();
        this.context.groupSet.forEach((p) => {
            p.player.setGameMode(GameMode.Adventure);
            p.player.setSpawnPoint();
            p.runCommand("effect @s clear");
            p.clear();
            p.player.teleport(
                { x: 1917, y: -60, z: 1906 },
                { dimension: Dimensions.Overworld }
            );
        });
        world.gameRules.pvp = false;
    }

    killEntity() {
        //省略
    }
}
```

## 如何创建游戏状态(GameState)

创建游戏状态，需要继承游戏模块.State 如下。

```ts
import { MyGameModule } from "../module";
export class MyState extends MyGameModule.State {
    //此方法必须写
    override onEnter(): void {
        //状态加载时执行
    }

    //此方法可以不写
    override onExit(): void {
        //状态退出时执行
    }
}
```

### GameState<P, C, TConfig, E> 常用属性与方法

> 注：以下仅列出常用成员，未注明修饰符的默认为 `public`。

#### 泛型参数

-   `P`: 玩家类型
-   `C`: 上下文（Context）类型
-   `TConfig`: 当前状态的配置类型（自定义）
-   `E`: 所属的 GameEngine 类型

> 使用 `class MyState extends GameModule.State<TConfig>` 时，仅需指定 `TConfig`（可选）。

例如:

```ts
export class PKParkourState extends parkourGameModule.State<PKParkourConfig> {
    get isTest() {
        return this.config?.isTest;
    }
    get team() {
        return this.config!.team;
    }

    override onEnter(): void {
        //如果没有传入config就退出
        if (this.config == undefined) {
            this.popState();
            return;
        }
    }
}
```

#### 属性

-   `config?: TConfig`: 状态配置对象
-   `engine: E`: 所属游戏引擎实例
-   `logger: Logger`: 日志工具
-   `runner: RunnerManager`: 异步执行管理器
-   `context: C` _(getter)_: 全局上下文，等同于 this.engine.context
-   `gameKey: string` _(getter)_: 游戏唯一标识，等同于 this.engine.key
-   `playerManager: GamePlayerManager<P>` _(getter)_: 玩家管理器，等同于 this.engine.playerManager
-   `lastState` _(getter)_: 上一个状态
-   `nextState` _(getter)_: 下一个(子)状态

#### 方法

-   `protected onEnter(): void` _(abstract)_: 状态进入时调用
-   `protected onExit(): void`: 状态退出时调用
-   `protected pushState(stateType, config?): void`: 添加新状态（相当于 engine.pushState()）
-   `protected popState(): void`:弹出当前状态（相当于 engine.popState()）
-   `protected transitionTo(stateType, config?): void`: 替换当前状态及所有子状态
-   `addComponent<C>(component:C, options?, tag?:string): this`: 添加组件(C 是组件的类，创建实例由框架完成)
-   `addComponents(components: GameComponentType[]): void`: 批量添加组件（不支持参数）
-   `getComponent<C>(type, tag?): InstanceType<C>`: 获取组件实例，不存在则抛错
-   `deleteComponent(component, tag?:string): this`: 删除指定组件
-   `protected subscribe<T>(event, ...args): EventSubscription | undefined`: 订阅事件
-   `stats(): string`: 返回状态调试信息

### 示例

```ts
import { Game } from "@begame/core";
import { DirtShopMapLoader } from "../components/loader";
import { DirtShopMoudle } from "../module";
import { EffectIds } from "@begame/core/utils/vanila-data";
import { GameMode } from "@minecraft/server";
import { DirtShopMainState } from "./mainState";

export class DirtShopLoadState extends DirtShopMoudle.State {
    protected override onEnter(): void {
        //添加组件
        this.addComponent(DirtShopMapLoader);
        this.initPlayer();

        //订阅事件
        this.subscribe(Game.events.interval, () => {
            this.context.groupSet.forEach((p) => {
                p.addEffect(EffectIds.InstantHealth, 20, 10);
            });
        });
    }

    initPlayer() {
        //访问全局context中的对象
        this.context.groupSet.forEach((p) => {
            p.player.setGameMode(GameMode.Survival);
            p.clear();
            p.runCommand("effect @s clear");
            p.player.teleport(this.context.map.loadPos);
        });
    }

    next() {
        //转换到下一状态
        this.transitionTo(DirtShopMainState);
    }
}
```

## 如何创建游戏组件 (GameComponent)

创建游戏组件分为专用组件和通用组件。

专用组件创建方式如下:

```ts
import { GameComponent } from "@begame/core/gameComponent";
import { MyState } from "xxx";

export class MyComponent extends GameComponent<MyState> {
    override onAttach(): void {
        //组件挂载时执行
    }
}
```

通用组件创建方式如下:

```ts
import { GameComponent } from "@begame/core/gameComponent";

export class MyCommonComponent extends GameComponent<GameState<any>> {
    override onAttach(): void {
        //组件挂载时执行
    }
}
```

### GameComponent<S,O> 常用属性与方法

#### 泛型

-   `S`: 组件所属的状态类型（继承自 GameState）

-   `O`: 组件配置类型（可选）

#### 属性

-   `state: S` — 当前所属状态

-   ` options?: O` — 组件配置

-   `tag?: string` — 组件标签

-   `context` _(getter)_ — 全局上下文(来自 engine)

-   `runner` _(getter)_ — 异步执行管理器(等价于 this.state.runner)

-   `isAttached`_(getter)_ — 是否已挂载

#### 方法

-   `protected onAttach(): void` _(abstract)_ — 当组件挂载到状态时调用
-   `protected onDetach(): void` — 当组件卸载时调用（可重写）
-   `protected subscribe(event, ...args): EventSubscription | undefined` — 订阅事件
-   `protected unsubscribe(sub: EventSubscription): void` — 取消订阅事件

### 示例

专用组件:

```ts
import { system, Vector3, world } from "@minecraft/server";
import { GameComponent } from "@begame/core/gameComponent";
import { Game } from "@begame/core";
import { Duration, Vector3Utils } from "@begame/core/utils";
import { DirtShopMainState } from "../states/mainState";

export class DirtShopBed extends GameComponent<DirtShopMainState> {
    protected override onAttach(): void {
        //检测床
        this.subscribe(
            Game.events.interval,
            () => {
                if (this.context.bedExists) {
                    this.checkBed();
                }
            },
            new Duration(10)
        );
        //防止床被房主挖
        this.subscribe(world.beforeEvents.playerBreakBlock, (t) => {
            if (!this.context.host.has(t.player)) return;
            if (this.isBedPos(t.block.location)) {
                t.cancel = true;
                system.run(() => {
                    t.player.onScreenDisplay.setActionBar("你不能破坏自己的床");
                });
            }
        });
        //防止床被炸
        this.subscribe(world.beforeEvents.explosion, (t) => {
            const blocks = t.getImpactedBlocks();
            t.setImpactedBlocks(
                blocks.filter((b) => !this.isBedPos(b.location))
            );
        });
    }

    isBedPos(loc: Vector3) {
        //略
    }

    checkBed() {
        //略，(主要逻辑是检测床是否存在)
    }
}
```

通用组件:

```ts
//内部导入，请以实际为准
import { GamePlayer, PlayerGroupSet } from "@begame/core/gamePlayer";
import { GameRegion } from "@begame/core/gameRegion";
import { GameState } from "@begame/core/gameState";
import { Game } from "@begame/core";
import { Duration } from "@begame/core/utils";
import { GameComponent } from "../gameComponent";

export interface PlayerRegionMonitorOptions<P extends GamePlayer> {
    region: GameRegion;
    interval: Duration;
    groups: PlayerGroupSet<P>;
    onLeave: (player: P) => void;
}

/**玩家区域监测 */
export class PlayerRegionMonitor<P extends GamePlayer> extends GameComponent<
    GameState,
    PlayerRegionMonitorOptions<P> //配置
> {
    override onAttach(): void {
        if (!this.options) return;
        this.subscribe(
            Game.events.interval,
            () => this.detectOutOfRegionPlayers(),
            this.options.interval
        );
    }

    private detectOutOfRegionPlayers() {
        const region = this.options!.region;
        this.options!.groups.forEach((p) => {
            if (!region.isInside(p.player.location)) {
                this.options!.onLeave(p);
            }
        });
    }
}
```
