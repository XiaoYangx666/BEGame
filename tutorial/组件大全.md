# 通用组件大全

> 当前正式包名为 `@begame/core`。本页只介绍推荐 API；旧名称仅在“兼容 API”中保留。

## 组件一览

### 生命周期
- ChunkScope — 将一组子组件绑定到区块可用生命周期
- `AutoStopComponent` — 本局无人参与时自动结束
- `DisconnectTimeoutComponent` — 玩家掉线超时处理
- `Timer` / `StopWatch` — 倒计时与秒表

### 玩家
- PlayerLifecycle — 将原生 death/spawn 映射回 GamePlayer / PlayerGroup
- SpawnController — 多组玩家出生点、传送与安全区
- RegionBoundary — 监控一个 PlayerSource 是否越界
- `PlayerTextPrimitive` — 玩家头顶文本
- `BlockInteractionBlocker` / `EntityInteractionBlocker` — 玩家交互限制

### 战斗
- `PvpController` — 按玩家/区域范围控制 PvP
- `FriendlyFireProtector` — 同队友伤保护

### 区域
- `RegionTeamChooser` — 区域选队，并可通过 `membershipRegion` 清理离开整个大厅的队伍关系
- `RegionProtector` — 区域内/外的方块破坏与交互保护
- `StructureProtector` — 基于 mcstructure 位图的通用地图方块保护（原图不可破坏、非法放置回滚）

### 展示
- SidebarScoreboard — 唯一正式侧边栏 Component
- teamScoreboard() — PlayerGroup[] → SidebarScoreboard preset
- `PlayerTextPrimitive` + `playerInfoText()` 等文本 preset

## ChunkScope

```ts
this.addComponent(ChunkScope, {
    dimensionId: DimensionIds.Overworld,
    pos: lobbyRegion.center,
    onLoad: (scope) => {
        scope.addComponent(RegionTeamChooser, { /* ... */ });
        scope.addComponent(SidebarScoreboard, { /* ... */ });
    },
    onUnload: () => {
        teams.forEach((team) => team.clear());
    },
});

this.getComponent(ChunkScope).reload();
```

`onLoad` 中通过 `scope.addComponent()` 创建的组件由 Scope 拥有。区块卸载、`reload()` 或 Scope 自身卸载时会逆序清理；`onLoad` 失败也会回滚已创建子组件。

## RegionBoundary

适合“已经属于游戏的这批玩家不能离开地图”的场景。

```ts
this.addComponent(
    RegionBoundary,
    regionBoundary({
        region: this.context.map.region,
        players: this.context.groupSet,
        interval: new Duration(10),
        onLeave(player) {
            player.player?.kill();
        },
    })
);
```

它和 `Game.events.region` 的定位不同：

- `Game.events.region`：观察全服原生玩家进出世界区域；
- `RegionBoundary`：只观察一个明确的 `PlayerSource`。

首次扫描已在区域外会触发一次 `onLeave`；保持在外不会重复触发，重新进入后再次离开才会再次触发。

## RegionTeamChooser

```ts
scope.addComponent(RegionTeamChooser, {
    membershipRegion: this.lobbyRegion,
    config: [
        { region: redRegion, team: this.red },
        { region: blueRegion, team: this.blue },
    ],
});
```

- Enter 选队区域时才会尝试 `playerManager.join()`；
- 进入另一队会从其它受管队伍移除；
- `membershipRegion` 表示整个选队大厅，离开时会从本 Chooser 管理的所有队伍删除；
- `removeOnLeave` 只控制离开某个单独选队区域时是否退该队。

## PlayerLifecycle

```ts
this.addComponent(
    PlayerLifecycle,
    playerLifecycle({
        players: this.context.groupSet,
        onDeath: ({ player, group, event }) => {
            // 生命数、死亡文案、淘汰规则属于游戏层
        },
        onSpawn: ({ player, group, event }) => {
            // 装备、传送等具体业务逻辑
        },
    })
);
```

组件只负责事件映射，不自动处理死亡文案、生命数、装备或淘汰。

## SpawnController

```ts
this.addComponent(SpawnController, {
    dimension: Dimensions.Overworld,
    bindings: [
        { players: redTeam, position: redSpawn },
        { players: blueTeam, position: () => blueTeam.data.spawnPoint },
    ],
    teleportOnAttach: true,
    interval: new Duration(10),
    safeArea: {
        resetRadius: { x: 1, y: 1, z: 1 },
        maintainRadius: { x: 0, y: 0, z: 0 },
    },
});
```

随机选择哪个出生点仍应由游戏层完成。若同一玩家异常存在于多个 binding，第一个 binding 优先。

## SidebarScoreboard

### 命令式

```ts
this.addComponent(SidebarScoreboard, {
    scoreboardName: `room_${this.engine.key}`,
    displayName: "§a游戏信息",
    showOnAttach: true,
});

this.getComponent(SidebarScoreboard).updateLines([
    "剩余玩家: §b3",
    "下一事件: ...",
]);
```

不同并行游戏实例应使用不同 `scoreboardName`。

### 队伍 preset

```ts
this.addComponent(
    SidebarScoreboard,
    teamScoreboard({
        scoreboardName: "lobby_teams",
        displayName: "选队",
        teams: [
            { team: redTeam, prefix: "§c" },
            { team: blueTeam, prefix: "§b" },
        ],
    })
);
```

`teamScoreboard()` 会监听 `PlayerGroup.changed` 自动刷新 membership 变化。若内容依赖 `player.no`、`status` 等普通业务属性，应在属性变化后手动调用 `SidebarScoreboard.refresh()`。

## PlayerGroup / PlayerGroupSet

推荐将队伍 membership 变化统一通过 `PlayerGroup` / `PlayerGroupSet` 操作。当前 `PlayerGroupSet`：

- 对 `getAllPlayers / forEach / validSize` 按 playerId 去重；
- `findGroupById()` / `findById()` 返回首个所属组；
- `areInSameGroup()` 用于友伤判断；
- `removePlayer()` 会从所有重复组清理指定玩家；
- `clone()` 保留 `TData`。

## 兼容 API

以下名称仍保留，但新代码不应继续使用：

| 旧 API | 推荐替代 |
|---|---|
| `LazyLoader` | `ChunkScope` |
| `PlayerRegionMonitor` | `RegionBoundary + regionBoundary()` |
| `RespawnComponent` | `PlayerLifecycle + playerLifecycle()` |
| `SpawnPointProtector` | `SpawnController` |
| `InfoScoreboard` | `SidebarScoreboard` |
| `TeamScoreBoard` | `SidebarScoreboard + teamScoreboard()` |
| `RegionTeamCleaner` | 选队大厅用 `membershipRegion`；其它场景用 `RegionBoundary` |
