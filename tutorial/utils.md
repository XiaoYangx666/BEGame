# Utils 工具列表

-   Algorithm(NameSpace)
    包含多种通用算法函数，方便在游戏逻辑中使用。

-   ChunkUtils
    区块计算相关工具

-   Duration

    时间持续量，用于表示时间。

-   func(NameSpace)
    js 常用函数
-   Logger
    日志工具(已内置在 state)
-   RandomUtils
    随机工具，包含很多随机方法
-   Vector3Utils
    三维向量工具类，用于计算
-   vanilaData(NameSpace)
    原版数据，只有一些常用的
